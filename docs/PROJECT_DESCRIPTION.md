# 项目描述

## 项目名称

OfferLab：央国企校招岗位发现与比较工具

## 项目背景

央国企校招岗位分散在不同招聘官网，同一名称的岗位在不同企业中可能有不同职责，职责相近的岗位也可能使用完全不同的名称。应届生通常需要逐个搜索招聘网站、阅读 JD、判断资格，再自行记录和比较岗位。

## 项目目标

根据用户的学历、专业、技能、项目经历、目标方向和意向地点，从已收集的校招岗位中筛选较适合的岗位，并通过 JD 原文解释推荐结果，帮助用户完成岗位发现、资格核对和横向比较。

## 主要流程

1. 用户填写画像或导入简历文本；
2. 系统识别明确技能、专业基础和可迁移能力；
3. 根据基础资格和地点筛选候选岗位；
4. 根据目标方向、职责、技能、专业和项目经历进行排序；
5. 展示匹配优势、待补技能和 JD 证据；
6. 用户选择 2–3 个岗位进行横向比较；
7. 用户对推荐结果进行三级相关性标注，用于后续评测。

## 技术与数据方案

- 岗位数据统一整理为结构化 JSON，并保留官方来源链接；
- 使用字符 2–4 gram TF-IDF、同义词、字段权重和规则完成低成本匹配；
- 将基础资格判断与技能匹配分开处理；
- 将技能分为明确掌握、可迁移能力和待补技能；
- 使用 NDCG@10、Precision@10 和人工三级相关性标签评估推荐质量；
- 保留开发集、冻结测试集和真实用户标注，避免不同阶段的数据混用。

## 当前结果

- 原型展示 259 条岗位，覆盖 18 家央企集团；
- 6 家集团完成官方岗位全量扫描，共读取 5,216 条原始岗位；
- 3 名用户完成首轮 30 条推荐结果标注；
- P3 的 Precision@10 从 v0.1 的 20% 提升到 v0.3 的 80%；
- v0.3 P3 NDCG@10 为 94.60%；
- 能力推断测试 10/10 通过。

## 当前限制

项目是本地实验版本。企业和岗位覆盖不完整，岗位具有时效性，用户评测样本也较少。系统输出用于辅助筛选和比较，不代表录取概率或最终求职建议。
