# 金标准标注指南 v1.0

## 标注单位

以一条官方岗位 JD 为基本单位。公告中的集团级规则单独保存，并通过 `recruitment_program_id` 关联，不重复改写到每条岗位原文。

## 证据规则

1. `evidence_span` 必须是 JD 中连续出现的原文；
2. 选择能够支持结论的最短完整片段；
3. 同一结论需要多处文本时可保留多个证据；
4. 不能用岗位标题替代职责或技能证据；
5. 页面不可见或需要登录的内容不进入公开数据集。

## 技能级别

- required：必须、熟练掌握、能够独立使用等明确强制措辞；
- expected：掌握、具备、能够使用等正常要求；
- preferred：优先、加分项、有经验者优先；
- exposure：了解、接触过、熟悉者优先；
- unknown：措辞无法稳定分类。

两个标注者意见不同时，先保留各自标签和理由，再由项目负责人裁决。不得为了提高模型分数反向修改金标准。

## 专业与资格

- “统计学类”覆盖统计学；
- “数学类”是否覆盖统计学取决于招聘方专业目录，未给目录时标 unknown；
- “相关专业”标 unknown；
- “优先”不是硬资格；
- 本科和研究生专业要求分别保存；
- 意向地点不参与默认资格判断，用户主动选择地点时才过滤；
- 语言条件仅在 JD 明示时标注，不做证书自动换算。

## 相关性标签

针对具体用户查询标注：

- 2：职责与技能高度相关，应进入前 5；
- 1：部分相关，可以召回但无需高排；
- 0：实际职责不相关；
- U：信息不足。

每个“标题不同但应高排”的样本必须写一句人工理由。
