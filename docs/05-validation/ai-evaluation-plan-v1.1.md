# AI离线评测计划 v1.1

> 本版本取代v1.0的数据规模设计。评测对象、质量门槛和预算约束继续沿用v1.0。

## 数据集设计

数据分为岗位语料库、训练集、开发集和冻结测试集：

- 岗位语料库：不少于150条公开、可核验的2027校招岗位，覆盖不少于20家央企集团；
- 训练集：90条人工金标准，用于归一规则、示例、同义词和可选轻量排序实验；
- 开发集：30条人工金标准，用于方案选择、阈值和错误分析；
- 冻结测试集：30条人工金标准，在规则冻结后抽取并用于最终验证；
- 其余合格岗位保留在语料库，可用于搜索和演示，但不参与当前评测指标计算。

## 企业来源

候选来源扩展为国务院国资委2026年7月11日公布的99家中央企业。完整机器可读名单见`data/sources/central-soe-universe-v0.1.json`。

采集不要求99家平均分配。优先选择公开岗位详情完整、包含数字化岗位且能稳定回溯的集团，同时设置集团占比上限，避免评测结果被单一企业模板主导。

## 分层要求

- 至少20家集团；
- 单一集团原则上不超过开发集15%；
- 产品、数据分析、经营分析、软件开发、算法、大数据、测试、网络安全、云计算、运维、数字化运营均有覆盖；
- 至少12条异名高相关正例；
- 至少10条同名或标题相近但职责低相关反例；
- 至少12条含required/preferred/exposure边界措辞；
- 至少8条关键信息缺失并应输出unknown；
- 地点覆盖至少12个城市。

## 人工金标准

每条开发集和测试集岗位标注：

- 招聘类型、届次、学历、专业、地点；
- 职责主题与原文证据；
- 技能、归一名称、要求级别和原文证据；
- 种子用户基础资格状态和技能覆盖状态；
- 对代表性查询的相关/不相关标签；
- 异名正例或标题误导反例说明。

## 指标

保留v1.0指标，并为检索增加：

- Recall@5与Recall@10；
- NDCG@5；
- 异名岗位Recall；
- 标题误导率；
- 每项指标同时报告分子、分母和置信限制。

当相关岗位数量超过K时，必须说明Recall@K的理论上限，不能把候选截断误判为模型失败。

## 冻结规则

开发阶段允许修改Schema、提示词、同义词、权重和规则。进入冻结测试前记录所有版本；测试集结果出来后，只记录错误，不围绕单条测试样本修补当前版本。

## 阶段通过条件

- 岗位语料库不少于150条；
- 90条训练集和30条开发集完成证据核验；
- Schema、提示词、规则和检索方案冻结；
- 30条测试集完成独立评测；
- 至少比较标题、标题加技能、关键词混合、同义词增强及语义检索方案；
- 输出成功样本、失败样本、来源偏差、成本和限制。
