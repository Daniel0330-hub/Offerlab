## 后续企业原则

- 优先搜索尚未进入语料库的央企集团；
- 同一新集团首轮原则上选取3–5个职责差异明显的岗位；
- 其余合格岗位进入待采集队列，待集团覆盖达到20家后再补齐；
- 已有集团只有在岗位族严重缺失时才重新开放收集。
