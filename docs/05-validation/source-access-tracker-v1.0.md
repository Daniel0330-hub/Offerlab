## 纳入条件

1. 来源属于集团、下属单位或官方招聘系统；
2. 明确为 2027 届校园招聘，或清楚列出 2027 届可投；
3. 能识别单个岗位名称和岗位边界；
4. 至少包含职责、资格条件或专业要求之一；
5. 保存官方 URL 和采集日期；
6. 若页面需要登录才能查看，不把搜索摘要直接当作完整 JD。

## 排除记录

- 2026 届及更早岗位：可用于错误案例，不能进入 2027 主数据集；
- 招聘服务采购公告：证明招聘活动存在，但不属于求职岗位；
- 第三方转载：可用于发现线索，不能作为金标准来源；
- 只有公司介绍、没有岗位信息的公告：保留在线索表，不进入岗位表；
- 搜索摘要混合多个岗位：必须回到官方页面人工分隔。
