# 阶段7：真实用户岗位相关性测试 v1.0

## 目标

验证系统根据不同用户画像产生的前10个岗位，是否真的被该用户认为与专业、技能、经历和目标方向相关，并为下一轮权重调整建立真实标签。

## 样本与任务

- 邀请原8名受访者中的3–5人；每人使用自己的专业、技能、项目经历和方向建立画像。
- 每人标注系统前10个推荐岗位，共形成30–50个“用户—岗位”判断。
- 标签为：2高度相关、1一般相关、0不相关。
- 用户可填写简短原因，优先记录错误专业、错误职责、技能差距过大、硬门槛和遗漏优势。

## 执行步骤

1. 清空上一位用户的浏览器会话或打开新的隐私窗口。
2. 用户填写画像并查看能力推断，纠正错误信息。
3. 打开“推荐评测”，先阅读统一标注口径。
4. 独立完成10条标注，不由研究者解释系统分数。
5. 导出JSON，以匿名编号命名为 `P01.json`、`P02.json`。
6. 将文件放入本地评测目录，运行 `python3 scripts/evaluate_user_relevance.py P01.json P02.json`。

## 指标与阶段门槛

- NDCG@10：目标不低于0.70；
- Precision@10：标签大于0的岗位占比，目标不低于70%；
- 高度相关岗位数：每位用户前10至少3个；
- 画像变化敏感性：不同方向画像的Top10重合率低于60%；
- 解释问题率：用户认为优势或缺口解释错误的岗位占比低于20%。

本轮只有达到3名真实用户后才调整权重。单个用户结果只用于发现问题，不直接修改规则，避免围绕个人偏好过拟合。
