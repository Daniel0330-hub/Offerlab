# 开发集 v0.3 复核报告

## 最终规模

- 岗位：20条，达到阶段5开发集目标；
- 集团：中国电信3条、中国移动7条、中国联通5条、中国中车5条；
- 城市：北京、合肥、南京、太原、大同、巴彦淖尔、海口、烟台、长春；
- 数据状态：20条全部通过自动质量检查；
- 数据用途：用于规则、权重、同义词和检索方案开发，不能作为独立测试集。

## 本轮新增岗位

1. 软件测试工程师：软件测试仿真、自动测试、工控网络和嵌入式开发；
2. 数据软件专业设计师：前后端开发、大模型训练部署、数据处理和AI解决方案；
3. 人工智能工程师：需求调研、算法实现、模型优化和工程化部署；
4. 大数据工程师：Java、Hadoop、Spark、Flink、Kafka、容器和分布式平台；
5. 数据分析工程师：振动数据分析、诊断算法、Matlab和Python。

以上岗位均来自中车长春轨道客车股份有限公司官方2027校园招聘系统，并保存单岗位URL和原文证据。

## Schema检查

- 职责、技能、基础资格及其他明确条件均可落入现有结构；
- 未在JD中出现的专业信息保持缺失，不根据岗位名称猜测；
- `graduation_years`已加入Schema必填字段，修复数据集与Schema约束不一致；
- CET-6、院校范围等条件保留在`other_explicit_conditions`，不混入核心技能。

## 来源偏差

- 通信运营商仍占15/20，中车占5/20；
- 尚未覆盖三桶油、电网、中储粮、国家电投和中国铁塔的合格单岗位正文；
- 所有新增中车岗位均在长春，地域仍不均衡；
- 这些限制必须在GitHub项目说明和评测报告中公开。

## 冻结前动作

1. 使用20条开发集比较人工同义词和语义向量方案；
2. 依据错误类型选择最终检索方案，而不是追求开发集满分；
3. 冻结Schema、规则、权重和提示词；
4. 冻结后另采集10条岗位作为独立测试集。
