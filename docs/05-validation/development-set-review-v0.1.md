- 企业集团：中国电信、中国移动；
- 城市：北京、合肥、南京、太原、大同、巴彦淖尔；

- 数据状态：全部通过 `scripts/validate_dataset.py`。

## 本轮覆盖的关键测试场景

- `掌握`、`熟悉`与`优先`的技能级别区分；
- Python/Java/C++“至少一种”不能拆成三项 required；
- 网络认证“优先”不能成为资格淘汰条件；
- 技术岗名称可能实际包含销售服务支撑，需要依据职责而不是标题排序；
- 一个综合技术岗位可能同时包含 IT 开发、数据治理、网络运维和安全职责；
- 统计学明确出现在专业范围时可保留证据，但仍要区分 required 与 preferred。
