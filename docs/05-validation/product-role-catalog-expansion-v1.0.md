# 产品岗位目录扩容 v1.0

## 问题

完整候选目录中已有大量产品岗位，但原来的每集团50条分层抽样由开发、算法和数据岗位主导。中国联通完整相关目录含58个标题明确的产品经理、产品管理、产品规划或产品运营岗位，其中北京16个；旧展示目录没有保留足够数量，导致AI产品画像即使排序正确也缺少候选供给。

## 修订

- 保持展示目录259条、18家集团、每集团最多50条的成本边界。
- 对每个集团先按JD完整度保留最多24个明确产品岗位，再用岗位族分层抽样补齐剩余额度。
- 只使用已经核验并保留原始链接的真实JD，不合成岗位。
- 专业、学历和届次等硬性资格仍参与默认预筛，不因产品岗位扩容而放宽。

## 结果

- 展示目录明确产品岗位：28条；
- 北京明确产品岗位：7条；
- P3画像（统计/应用数学、北京、SQL/Python、仅AI产品）中，医疗AI产品经理和AI产品经理升至前两位；
- 北京其他产品岗位若专业硬性条件不符，只能在“查看全部岗位”中核验，不进入默认推荐。

本次调整解决候选供给被抽样策略截断的问题。推荐质量仍需用新的用户标注验证，不能用目录数量代替相关性指标。
