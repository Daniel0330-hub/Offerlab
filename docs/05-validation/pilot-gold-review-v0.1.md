# 首批 5 条真实 JD 试标复核 v0.1

## 数据来源

- 中国电信 2027 校园招聘官方岗位页：3 条；
- 中国移动 2027 校园招聘官方岗位详情：2 条；
- 采集日期：2026-10-06；
- 数据文件：`data/evaluation/pilot-gold-v0.1.json`。

## 试标结果

1. 当前 Schema 可以表达职责、技能、届次、学历、专业、地点和证据；
2. 综合岗位页面可能把多个岗位内容连续展示，采集时必须按岗位边界人工核验；
3. JD 没有明确列出软件技能时，`skills` 应为空，不能从“AI应用”猜出 Python；
4. “专业优先”必须保留为 preferred，不能作为硬性 pass/fail；
5. 中国移动部分岗位把多个工作方向合并在一个职位中，职责标签需要允许多主题；
6. 工作地点来自岗位详情，可直接作为筛选字段，但不进入默认相关性分数。

## Schema 修改结论

试标 5 条后暂不修改 Schema。下一批需要重点寻找：

- 明确写出 Java/Python/SQL 等技能及要求级别的岗位；
- 含语言或证书要求的岗位；
- 含“相关专业”模糊表述的岗位；
- 多工作地点岗位；
- 软件开发、测试、网络安全和算法岗位。

## 数据质量风险

- 搜索结果摘要可能混入相邻岗位文本，不能直接批量当作单条 JD；
- 官方页面内容会更新，必须保存采集日期和原始链接；
- 当前仅有两个集团，不能据此评估 12 家企业的总体表现；
- 试标数据用于验证结构，不计入冻结测试集。
