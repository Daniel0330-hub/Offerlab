# AI 错误分类 v1.0

| 代码 | 错误 | 示例 | 严重度 |
|---|---|---|---|
| E01 | 无依据字段 | JD 未写 Java，模型自行补充 | 高 |
| E02 | 证据不可定位 | evidence_span 不存在于原文 | 高 |
| E03 | 要求级别错误 | “Java 优先”被标成 required | 高 |
| E04 | 技能错误合并 | Python 被视为 Java 已覆盖 | 高 |
| E05 | 硬条件误杀 | “相关专业”被直接判 fail | 高 |
| E06 | 硬条件误放 | 明确仅限 2026 届却判 2027 届通过 | 高 |
| E07 | 应 unknown 却猜测 | JD 未写地点却推断北京 | 中 |
| E08 | 异名漏召回 | 职责高度相关但因标题不同未返回 | 高 |
| E09 | 标题误导 | 标题相似、职责无关却排在前列 | 中 |
| E10 | 地点错误过滤 | 用户未选择地点时只返回北京 | 高 |
| E11 | 语言条件越权 | 自动把 TOEFL 换算为 CET | 高 |
| E12 | 解释夸大 | 写“非常适合”但证据只支持弱关联 | 中 |
| E13 | 比较遗漏 | 独有 required 技能未在比较中出现 | 高 |
| E14 | 格式失败 | JSON 无法通过 Schema | 中 |

修复优先级：可能造成误投/漏投的高严重度错误 → 影响证据可信度的错误 → 文案和格式问题。
