# 数据拆分规则 v1.0

## 比例

目标金标准数据按 **训练集60% / 开发集20% / 冻结测试集20%** 拆分。

以首个完整目标150条计算：

| 集合 | 数量 | 用途 |
|---|---:|---|
| 训练集 | 90 | 同义词归一、提示词示例、规则设计，以及可选轻量排序器训练 |
| 开发集 | 30 | 方案选择、权重和阈值调整、错误分析 |
| 冻结测试集 | 30 | 规则冻结后的独立结果报告 |

超过150条的合格岗位继续进入语料库；下一次版本升级时再按相同规则重新分层，当前冻结测试集保持不变。

## 为什么采用60/20/20

- 项目不是训练基础大模型，训练集主要服务于归一规则、示例选择和轻量排序实验，60%已经足够；
- 当前样本规模较小，开发集需要30条才能让方案比较和错误分析具有基本覆盖；
- 测试集保留30条，可以延续原独立测试目标，并覆盖更多新集团。

## 防泄漏规则

1. 优先按`parent_group`做集团级拆分，而不是完全随机拆分；
2. 同一岗位的不同城市版本、重复发布和近似副本必须进入同一集合；
3. 测试集优先包含训练集未见的集团或未见的JD模板；
4. 岗位族、地点和学历在三个集合中保持基本覆盖；
5. 冻结测试集生成后保存清单和哈希，不再因结果不理想而调换样本；
6. 当前24条仅属于已标注候选池，达到足够集团覆盖前不正式划分。
