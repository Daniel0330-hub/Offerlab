# 检索错误案例 v0.1

## R01：系统架构设计工程师被挤出前 5

- 查询：项目交付、解决方案、客户需求；
- 人工标签：相关；
- 岗位：中国联通北京分公司——系统架构设计工程师；
- 当前排名：前 5 之外；
- 直接原因：岗位职责使用“方案制定、运营支撑、需求沟通、研发测试”，没有出现“项目交付”和“客户需求”的完整词形；
- 竞争岗位：中国电信产品经理因“需求分析及产品设计”取得相同分数，并按稳定 ID 顺序进入前 5；
- 错误类型：E08 异名漏召回；
- 暂定修复方向：在下一轮加入经过人工审核的职责同义词，例如“需求沟通→客户需求”“方案制定→解决方案”，或使用 embedding 进行职责语义匹配；
- 当前处理：记录错误，暂不针对单条样本调权。

## 为什么不立即修复

开发集目前已达到20条。新增中国中车岗位后，Q05共有8个相关岗位，Recall@5的理论上限为62.5%，当前混合检索已达到该上限；系统架构设计工程师仍未进入前5。下一步将比较人工同义词和语义向量方案，并增加NDCG@5或更大的K值，避免把候选截断误判为语义召回失败。
