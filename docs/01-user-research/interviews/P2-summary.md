# P2 匿名访谈摘要

> 资料来源：2026-10-06 录音；约 2 分 59 秒。机器转写后进行语义整理。未保存真实姓名等身份信息。

## 当前行为

- 寻找实习时使用 BOSS 直聘、实习僧等招聘平台；
- 寻找正式校招或社招岗位时更倾向企业官网；
- 优先搜索已经了解的公司；缺少目标时依赖招聘软件推荐；
- 企业官网通常能明确区分校招和社招，综合招聘平台更容易混杂；
- 比较相似岗位时主要阅读各自 JD。

## 主要痛点

- 平台推荐不一定准确；
- 难以判断自己的能力是低于、符合还是明显高于岗位要求；
- 薪资、工作时长和真实工作情况等信息不足；
- 需要依靠朋友、论坛或其他非官方渠道补充判断。

## 期望改善

- 根据简历内容、学历、能力和实习经历综合召回合适岗位；
- 帮助判断能力层级，而不是只比较关键词。

## 对产品的启示

- 必须把官方明确条件与非官方经验信息分开；
- MVP 可以判断“证据覆盖程度”，但不能承诺判断真实录取水平；
- 对薪资、工时等缺失信息应显示未知，不应由 AI 猜测。
