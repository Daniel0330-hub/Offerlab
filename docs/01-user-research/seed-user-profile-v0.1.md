## 资格与相关性必须分开

### 资格判断

- 2027 届是否可申请；
- 硕士学历是否符合；
- 统计学或精算学是否在专业范围内；
- 北京是否为工作地点；
- 英语硬性条件是否符合；
- 是否存在其他必须条件。

### 相关性判断

- 是否涉及产品、数据、经营分析、数字化、风险或 AI 应用；
- Python、SQL 和统计训练是否能形成岗位证据；
- 用户当前是否具有岗位所需的产品实践；
- 缺口能否通过 OfferLab 项目形成可展示证据。

一个岗位可以“有资格但相关性低”，也可以“职责高度相关但因英语或专业条件无法申请”。界面不得将二者合并成单一匹配分。

## 当前最关键的信息缺口

1. 国内院校还是海外院校，以及具体毕业时间；
2. 北京是否为唯一接受地点；
3. 对营销、财务审计、风险和综合管理岗位的接受程度；
4. 是否接受入职后前往北京之外轮岗；
5. 学校、实习、项目和课程证据尚未结构化录入。
