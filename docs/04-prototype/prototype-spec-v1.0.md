# 可点击原型规格 v1.0

> 历史版本：已由 `prototype-spec-v1.1.md` 取代，保留用于展示用户反馈驱动的原型迭代。

## 原型目的

本原型验证信息和交互，不验证真实检索模型性能。岗位排序、资格状态和技能判断使用预计算演示数据，阶段 5 再实现并评测 AI 方案。

## 页面与关键状态

### 1. 我的能力画像

- 展示届次、学历、专业、地点、轮岗意愿；
- 以标签形式录入目标方向与技能；
- 技能可附项目证据；
- 保存后进入岗位发现。

### 2. 岗位发现与详情

- 支持关键词、公司和岗位族筛选；
- 结果卡首先解释“为什么找到”，其次展示资格和技能缺口；
- 卡片不展示适配百分比；
- 点击详情后查看职责、技能分级、用户证据与 JD 原文；
- 可选择最多三个岗位进入比较。

### 3. 岗位比较与志愿决定

- 以岗位为列，比较维度为行；
- 优先呈现职责主题、required 技能、技能缺口和待核实条件；
- 共同要求与独有要求分别展示；
- 每个岗位可记录“优先投递/备选/放弃”和理由。

## 视觉语义

| 状态 | 文案 | 用途 |
|---|---|---|
| 通过 | 满足 | 用户证据明确覆盖 |
| 风险 | 有缺口 | required/expected 技能不足 |
| 待核实 | 信息不足 | JD 或用户信息不足 |
| 不符合 | 不满足 | 明确硬条件冲突 |

颜色仅作为辅助，所有状态同时使用文字和图标，避免只靠颜色传递含义。

## 原型数据边界

- 使用 5 条脱敏演示岗位；
- 两条参考已核验的中国电信北京公司岗位方向；
- 其余为用于交互验证的合成岗位，不代表当前真实招聘；
- 所有演示岗位均标注“原型演示数据”；
- 原型不联网、不抓取、不调用模型。
