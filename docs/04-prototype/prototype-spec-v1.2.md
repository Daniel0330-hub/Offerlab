# 可点击原型规格 v1.2

## 本轮反馈

产品面向多生源地应届生。v1.1 的岗位地点均为北京，容易把种子用户的个人偏好错误地固化为产品范围，并漏掉其他城市的相关岗位。

## 产品决策

地点采用“全量召回 + 用户主动筛选”的方式：

1. 默认在全部工作地点中检索符合职责、技能和专业条件的岗位；
2. 用户可以在岗位发现页顶部选择工作地点；
3. 只有用户主动选择地点后，地点才成为当前结果集的过滤条件；
4. 能力画像中的意向地点允许填写多个，仅作为偏好，不默认排除其他地区；
5. 结果卡和比较页始终展示工作地点，避免用户忽略地域差异。

## 原型覆盖地点

北京、上海、广州、深圳、天津、南京、武汉、成都、西安、青岛。

这些地点用于交互测试，不代表各企业当前真实招聘安排。

## 待验证问题

- 用户是否理解“意向地点”与“当前地点筛选”的区别；
- 默认展示全国岗位是否造成信息过载；
- 用户是否会先按岗位内容浏览，再选择地点；
- 多地点岗位后续应采用城市级还是区域级筛选；
- 是否需要“接受异地/接受调剂/接受轮岗”作为单独偏好。
