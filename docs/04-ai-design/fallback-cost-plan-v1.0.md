# 降级与成本方案 v1.0

## 无 API 模式

- 仓库附带人工核验和预计算的结构化 JSON；
- 搜索使用本地关键词、同义词和可选本地向量；
- 资格判断全部由本地规则运行；
- 解释优先使用证据模板生成；
- 评审者无需密钥即可完成搜索、详情和比较。

## 有 API 模式

API 只用于离线处理新 JD 和生成受约束摘要，不在每次页面搜索时调用。处理结果缓存到本地，避免重复成本。

## 预算控制

- 总预算上限：50 元；
- 先在 5 条开发样本调通，再扩展至 20 条；
- 冻结提示词后才运行 10 条测试集；
- 每条岗位最多一次自动重试；
- 达到预算 80% 时停止非必要对照实验；
- 日志只记录 token、耗时和错误，不记录密钥。

## 运行失败

| 失败 | 降级 |
|---|---|
| API 不可用 | 使用缓存 JSON |
| JSON 不合法 | 一次格式修复，失败则人工复核 |
| 证据校验失败 | 丢弃该字段并标记错误 |
| embedding 不可用 | 回退关键词与同义词检索 |
| 摘要生成失败 | 使用固定证据模板 |
