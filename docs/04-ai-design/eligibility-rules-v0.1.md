# 校招资格判断规则 v0.1

> 历史版本：已由 `eligibility-and-skill-rules-v0.2.md` 取代。旧版将英语作为默认资格项，已不符合 PRD v1.1。

## 原则

资格判断是确定性规则优先的任务。大模型可以从 JD 中提取字段，但不能自行放宽岗位条件，也不能把软性相似度覆盖在硬性门槛之上。

## 输出状态

- `pass`：现有证据明确符合；
- `fail`：现有证据明确不符合；
- `unknown`：岗位或用户信息不足，需要核实。

## 总体判断

```text
如果任一强制条件为 fail：ineligible
否则如果任一强制条件为 unknown：needs_review
否则：eligible
```

## 规则优先级

1. 招聘类型；
2. 面向届次/毕业时间；
3. 学历；
4. 专业；
5. 英语及证书；
6. 地点；
7. 其他岗位特定要求。

## 专业判断

1. 优先使用招聘方列出的专业原文；
2. “统计学类”可覆盖统计学，但不能自动覆盖所有经济、金融或计算机专业；
3. “数学类”是否覆盖统计学，需要结合招聘方专业目录；未给目录时记为 `unknown`；
4. “相关专业”可以进入人工核实，不自动判定为 `pass`；
5. 本科和硕士专业要求分别保留，不默认只看最高学历专业；
6. 精算学不能自动改写为金融学、保险学或统计学。

## 英语判断

```text
无英语要求                         -> pass/not_applicable
英语能力良好 + TOEFL 100            -> pass（保留成绩证据）
必须 CET-4/6 + 用户无 CET           -> fail
CET-4/6 或同等成绩 + 未列换算标准    -> unknown
明确接受 TOEFL 且达到岗位阈值         -> pass
境外院校豁免或单列规则                -> 按公告判断
```

## 可解释输出示例

```json
{
  "criterion": "major",
  "status": "pass",
  "user_evidence": "硕士专业：统计学",
  "job_evidence": "统计学类等专业优先",
  "source_url": "官方岗位详情链接"
}
```

## 禁止行为

- 将托福自动换算成 CET 分数；
- 将“优先”误判成绝对强制要求；
- 根据职位名称猜测专业要求；
- 缺少字段时默认用户符合；
- 生成没有原文证据的资格解释；
- 用综合匹配分掩盖明确的硬性不符合。
