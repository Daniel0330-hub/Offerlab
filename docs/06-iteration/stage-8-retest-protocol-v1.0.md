# 阶段8 v0.2复测任务

## 参与者

优先邀请P3完成同画像复测，再邀请一名目标方向为产品经理或AI产品的用户交叉验证。每名用户独立完成，不展示v0.1标签和预期指标。

## 固定画像

- 2027届硕士；
- 专业：统计/应用数学；
- 地点：北京；
- 技能：SQL、Python；
- 目标方向：只选择AI产品。

## 操作

1. 刷新原型并重新填写固定画像；
2. 确认岗位发现默认只显示北京；
3. 在推荐评测页对10个岗位完成2/1/0标注；
4. 至少打开两个岗位的原版JD；
5. 导出JSON并命名为 `P3-retest-v0.2.json`；
6. 记录首个高度相关岗位、开发岗数量以及是否有相关产品岗被遗漏。

## 复测问题

- 前10里哪些岗位仍明显偏离AI产品？
- 医疗AI产品经理和AI产品经理是否属于你的可申请方向？
- 系统展示的专业资格和技能缺口是否改变判断？
- 是否存在你认为相关、但因专业规则被拦截的产品岗位？
- 原版JD入口是否容易发现？

## 评测命令

```bash
python3 scripts/evaluate_user_relevance.py P3-retest-v0.2.json \
  --output data/evaluation/user-relevance-P3-retest-v0.2.json
```
