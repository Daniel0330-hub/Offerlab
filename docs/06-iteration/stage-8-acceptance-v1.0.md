四项冻结门槛全部通过：Precision不低于0.70、高度相关岗位不少于3个、首个高度相关岗位不低于第2名、前5开发/算法岗位不超过2个。

## 关键学习

1. 组合意图不能拆成独立关键词。“AI产品”需要产品职责证据，不能由AI和产品分别命中替代。
2. 排序质量受候选供给上限影响。完整目录已有产品岗位，但抽样策略会决定用户能否看到它们。
3. 评测工具本身也需要审计。按点击顺序导出会污染NDCG，v0.3改为按当前模型排名导出并声明排序方式。
4. 硬资格必须继续独立。增加产品岗位不能把专业不符岗位强行推荐给用户。

## 已知限制

- 结果来自3名用户，v0.3重点复测来自同一P3画像，不能外推到所有专业和城市；
- 产品岗位主要来自已完成全量适配的集团，企业覆盖仍不均衡；
- “相关专业优先”在部分来源结构化为required，仍可能产生资格误杀；
- 相关性标签没有书面原因，无法进一步量化解释错误率。
