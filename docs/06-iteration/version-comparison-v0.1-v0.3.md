# v0.1至v0.3迭代摘要

真实用户评测发现，v0.1对数据和开发画像表现尚可，但AI产品画像Precision@10只有20%。团队没有以整体NDCG掩盖该失败，而是连续修正组合语义、地点约束、产品岗位供给和评测导出顺序。

最终v0.3在相同目标方向复测中达到Precision@10 80%、NDCG@10 94.60%和5个高度相关岗位。相比v0.1，Precision提高60个百分点；相比未达标的v0.2正式复测提高20个百分点。

完整修改和失败过程见：

- `version-comparison-v0.1-v0.2.md`；
- `stage-8-retrospective-v0.2.md`；
- `stage-8-acceptance-v1.0.md`。
