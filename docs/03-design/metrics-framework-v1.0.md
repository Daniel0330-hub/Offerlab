# MVP 指标体系 v1.0

> 历史版本：已由 `metrics-framework-v1.1.md` 取代。

## 北极星实验指标

**有依据的志愿决策完成率**

定义：在测试任务中，用户完成 2–3 个岗位比较，查看至少一项证据或待核实项，并记录最终选择理由的比例。

这不是商业北极星指标，而是本地实验用来判断核心流程是否成立的指标。

## 产品可用性指标

| 指标 | 定义 | 目标 |
|---|---|---:|
| 核心任务完成率 | 成功完成画像确认、资格查看、比较和选择的用户比例 | ≥80%，样本不少于 3 人 |
| 资格状态理解正确率 | 用户能正确解释符合、不符合和待核实 | ≥90% |
| 重要差异发现数 | 用户通过比较页发现的原先忽略差异 | 每人 ≥1 个 |
| 任务耗时 | 完成同一岗位筛选和比较任务所需时间 | 比手动基准下降，或错误明显减少 |
| 阻断性错误数 | 导致用户无法完成任务的问题 | 0 |
| 证据查看率 | 测试中至少展开一次原文证据的用户比例 | ≥67% |

## AI 与规则质量指标

| 指标 | 说明 |
|---|---|
| 字段提取准确率 | 招聘类型、届次、学历、专业、英语、地点、截止时间分别计算 |
| 资格误放率 | 人工判定不符合，但系统判为符合 |
| 资格误杀率 | 人工判定符合，但系统判为不符合 |
| unknown 合理率 | 人工认为需要核实的条件被系统正确标记 |
| 证据引用正确率 | 引用原文是否直接支持判断 |
| 无依据结论数 | 没有原文证据却输出确定结论的数量，目标为 0 |

具体阈值在阶段 5 基线评测后冻结，避免在没有数据时虚构准确率目标。

## 过程指标

- 人工核验岗位数；
- 有完整官方来源的岗位比例；
- 有截止时间或明确 unknown 的岗位比例；
- 已覆盖的资格边界案例数；
- 已记录失败案例数；
- 从用户问题到需求、测试的追溯覆盖率。

## 不使用的指标

- 注册用户数；
- DAU/MAU；
- 商业收入；
- Offer 数量；
- 虚构的面试率提升；
- 无真实结果支持的录取概率。
