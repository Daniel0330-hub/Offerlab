# 指标框架 v1.1

## 北极星实验指标

**有依据候选集形成率**：用户能否找到至少 3 个相关岗位，理解召回原因，并选出 2–3 个进入比较。目标为 3–5 名测试用户中至少 80% 完成。

## 岗位发现指标

| 指标 | 定义 | MVP 目标 |
|---|---|---:|
| Recall@5 | 人工标注相关岗位中出现在前 5 条的比例 | ≥ 80% |
| 异名岗位召回率 | 名称不相似但 JD 高相关岗位被找到的比例 | ≥ 75% |
| 标题误导率 | 名称相似但职责明显不相关的岗位进入前 5 条的比例 | ≤ 20% |
| 召回理由正确率 | 召回理由可由 JD 原文支持 | ≥ 90% |

样本量小时同时报告分子、分母，不把结果包装为统计显著结论。

## 资格与技能判断指标

| 指标 | 定义 | MVP 目标 |
|---|---|---:|
| 基础资格准确率 | 届次、学历、地点等与人工金标准一致 | ≥ 90% |
| 技能抽取准确率 | 技能名称、要求级别和证据与人工标注一致 | ≥ 85% |
| 无依据断言率 | 缺少证据仍下确定结论 | 0% |
| 信息不足识别率 | 无法判断时正确输出“信息不足” | ≥ 90% |

## 用户任务指标

- 完成搜索、详情理解、加入比较和最终决定的任务成功率；
- 首个有效岗位发现时间和形成比较集所需时间；
- 能否复述一个岗位的核心职责和技能缺口；
- 是否发现至少一个原本会因名称不同而忽略的岗位；
- 决定信心变化和对解释的信任原因。

## 过程指标

- 20–30 条岗位样本全部附官方来源和采集日期；
- 每条 JD 的结构化字段与原文证据均经检查；
- 评测集包含异名高相关、同名低相关和技能硬缺口三类反例；
- 所有错误进入 error analysis，并完成至少一轮修订。
