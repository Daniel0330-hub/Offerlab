## Won't Have This Version

- 全网岗位抓取；
- 登录、账户和云同步；
- 自动网申；
- 自动改写简历；
- 面试模拟；
- 薪资与工时社区；
- 邮件或微信提醒；
- 录取概率；
- 基于大量用户结果训练推荐模型；
- 移动端原生应用。

## 优先级规则

任何新增需求必须满足以下全部条件才能进入 v0.1：

1. 直接服务资格审计或有限志愿比较；
2. 能在现有 20–30 条样本上验证；
3. 不依赖账户、实时爬虫或外部付费数据；
4. 不延误 AI 评测和用户测试；
5. 有明确验收标准。
