# MVP 范围冻结记录 v1.0

> 历史版本：已由 `scope-freeze-v1.1.md` 取代。

> 冻结日期：2026-10-06  
> 对应里程碑：第 1 周 Day 7 产品定义完成

## 冻结的产品定位

面向央企校招有限志愿场景的证据化资格审计与岗位比较实验。

## 冻结的三个模块

1. 用户资格画像；
2. 岗位候选列表与逐项资格审计；
3. 2–3 个岗位的有限志愿比较与用户选择。

## 冻结的数据范围

- 20–30 条人工核验公开岗位；
- 优先三大运营商，进度允许时加入三桶油；
- 至少包含明确符合、明确不符合和待核实三类边界样本；
- 所有岗位均保留官方来源和原始文本；
- 使用一个脱敏种子用户画像完成演示。

## 冻结的页面

1. 我的资格画像；
2. 候选岗位与资格详情；
3. 志愿比较。

岗位详情作为候选列表的同页展开区或详情面板，不新增复杂路由。

## 冻结的 AI 范围

- JD 字段提取；
- 职责主题提取；
- 相关性解释；
- 岗位比较摘要。

硬性资格由规则计算；AI 只负责抽取和解释。无 API 时使用预计算结果。

## 不进入 v0.1

- 实时爬虫；
- 账户系统；
- 自动网申；
- 简历优化；
- 面试准备；
- 薪资和工作强度数据库；
- 消息提醒；
- 长期投递复盘；
- 录取概率；
- 第四个以上的核心页面。

## 变更控制

新增需求只能进入 `future-roadmap.md`。只有核心流程无法完成、测试发现严重误导或数据结构无法支持验收时，才能修改冻结范围，并必须在项目日志记录原因、影响和替代方案。
