# 信息架构 v1.1

> 状态：阶段 3 当前基线。页面仍控制为三页，但主链路增加岗位发现。

## 页面 1：我的能力画像

- 基本条件：毕业年份、学历、专业、目标地点、是否接受轮岗；
- 技能与工具：Python、SQL、Java、Axure 等，可补充熟练度和项目证据；
- 经历与方向：项目、实习、行业兴趣；
- 完整度提示和编辑入口。

英语不设为核心画像项。若 JD 明确提出语言证书或能力要求，在岗位详情的“其他明确条件”中展示原文和状态。

## 页面 2：岗位发现与详情

### 搜索区

- 搜索框：支持岗位方向、职责词、技能或公司；
- 筛选项：届次、公司、地点、岗位族；
- 搜索结果数量和当前条件。

### 结果卡片

- 公司、岗位名称、地点、来源；
- “为什么找到”：命中的职责和技能；
- 基础资格状态；
- 技能覆盖、关键缺口和信息不足；
- 查看详情、加入比较。

### 详情面板

- JD 原文与结构化职责；
- 技能要求及“必需/期望/优先/了解”级别；
- 每项判断的原文证据；
- 其他明确条件；
- 用户操作。

## 页面 3：岗位比较与志愿决定

- 2–3 个岗位并列比较；
- 对比职责方向、必需技能、优先技能、资格风险、地点和志愿规则；
- 显示岗位独有要求与共同要求；
- 记录“加入志愿/备选/放弃”及理由。

## 核心导航

```text
能力画像 → 岗位发现 → 岗位详情 → 加入比较 → 横向比较 → 用户决定
                  ↘ 修改搜索或筛选 ↗
```
