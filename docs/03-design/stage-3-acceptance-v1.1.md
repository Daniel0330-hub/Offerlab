# 阶段 3 产品定义与需求设计验收 v1.1

## 修订原因

v1.0 将“竞品已有岗位搜索”误解成“MVP 可以不做”。岗位发现是形成比较集的必要上游，差异应体现在召回依据。

## 验收结果

- [x] 主链路覆盖岗位搜索、JD 匹配、详情解释和横向比较；
- [x] 降低岗位名称权重，提高职责和技能权重；
- [x] 支持召回名称不同但 JD 高相关的岗位；
- [x] Java、Python、SQL 等软件和技能进入资格判断；
- [x] 区分技能的必需、期望、优先和了解级别；
- [x] 英语退出核心画像和独立召回权重；
- [x] JD 明示英语条件时，作为其他明确条件展示，不推断证书等价；
- [x] 页面仍为三页，数据仍为 20–30 条本地核验样本；
- [x] 用户故事、信息架构、指标、验收标准、数据结构和范围已同步。

## 结论

阶段 3 修订验收通过。阶段 4 原型和阶段 5 AI 评测以 v1.1 为执行基线。
