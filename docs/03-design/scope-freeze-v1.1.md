# MVP 范围冻结记录 v1.1

## 冻结目标

在三周和 50 元预算内，验证“JD 驱动的岗位发现 + 技能资格判断 + 横向比较”能否帮助应届生形成并缩小候选集。

## 四个功能模块

1. 能力画像：基本条件、专业、技能、经历与证据；
2. 岗位发现：在 20–30 条核验样本中搜索，按 JD 职责和技能优先排序；
3. 资格与技能判断：基础资格三状态、技能覆盖与原文证据；
4. 横向比较：比较 2–3 个岗位并记录用户决定。

## 三页界面

1. 我的能力画像；
2. 岗位发现与详情；
3. 岗位比较与志愿决定。

## 数据和技术边界

- 20–30 条来自目标企业官方渠道的脱敏岗位样本；
- 人工采集和核验，MVP 不承诺实时更新；
- 可使用本地规则、关键词/向量相似度或小规模模型调用；
- 演示不依赖付费 API；
- 不做全网爬虫、自动投递、账号体系和生产部署。

## 不可删减的差异化证据

- 至少一个名称不同但 JD 高相关的岗位能被召回；
- 至少一个名称相似但 JD 低相关的岗位不会仅凭名称排在前列；
- Java、Python、SQL 等技能可从 JD 提取、分级并与用户证据比较；
- 每个判断均可回溯到原文；
- 用户保留最终选择权。

新增需求先进入 `future-roadmap.md`。只有影响主链路正确性的缺陷可进入当前版本，并须写入项目日志。
