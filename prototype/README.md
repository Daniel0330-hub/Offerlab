# OfferLab v0.3 本地原型

## 启动

```bash
python3 -m http.server 8000 --directory prototype
```

打开 <http://127.0.0.1:8000>。原型只使用HTML、CSS和JavaScript，也可以直接打开`index.html`。

## 页面

1. 能力画像：专业、地点、目标方向、技能、项目证据和可迁移能力；
2. 岗位发现：画像—JD分项匹配、资格状态、优势、缺口和原版JD；
3. 横向比较：并列比较2–3个岗位并记录投递决定；
4. 推荐评测：对Top 10做2/1/0标注并按模型排名导出JSON。

## 数据与边界

- `jobs-data.js`包含259条真实岗位、18家集团，每集团最多50条；
- 画像地点默认约束推荐，可切换“查看全部岗位”；
- 页面不生成录取概率，不把技能缺口等同于硬资格失败；
- 数据和个人决定只保存在当前浏览器会话，不上传服务器；
- 岗位为截至2026年10月的实验快照，投递前应打开原版JD确认。
